# Tango

Tango has moved into **Puzzles**, together with the other puzzles:

- Play: https://magnustjerneld.github.io/Puzzles/#tango
- Source: https://github.com/MagnusTjerneld/Puzzles

This repository now only serves a redirect from the old address, `https://magnustjerneld.github.io/Tango/`. The page also removes the old app's service worker and offline cache, so nobody stays stuck on the old version. Progress is kept: it is stored per origin, and Puzzles reads the same keys.

The old game's code is in this repository's history.

If you installed the old Tango app, uninstall it and install Puzzles instead.
